# 배포 전 점검 — 2026-09-11

## 기준

첨부 `find-my-legend-beginner-update.zip`의 Next.js 정적 앱을 그대로 보완했다.
기존 49장 전설, 세트 날짜, 도메인/스타일 값, 질문 가중치, 추천 알고리즘, 경험별 패널티 및 CSS 테마는 변경하지 않았다. 실제 신규 카드 정보는 추가하지 않았다.

## 수정

- JSON 정규화 시 recommendationReady=false 보존. 점수·난이도가 불완전한 가져오기는 추천 비활성 상태 유지.
- localStorage 복원 시 같은 검증 경로를 적용하여 손상된 데이터의 앱 종료 방지.
- 마지막 초보자 질문의 보드/유닛 용어 제거. 질문 가중치는 유지.
- 순위가 달라지는 경우 입문 추천 1위 / 순수 취향 일치 1위 명시.
- 목록의 추천 준비 중 표시 및 상세 입문 난이도 안내 추가.
- 추천 후보가 없는 결과·설정 화면 안내 보완.
- 선택한 카드풀의 결과 점수가 목록·비교에서 바뀌지 않도록 동일 결과 사용.
- 자정 및 탭 복귀 시 출시일과 메모된 후보 목록 갱신.
- 공유 링크의 경험·범위·보조 세트·답변 값 검증 강화.
- GitHub Pages configure-pages@v5의 base_path 사용, upload-pages-artifact@v4 및 .nojekyll 적용.
- 추가 회귀 테스트 5개, 앱 통합 테스트 6개. 테스트 전용 @testing-library/react와 jsdom 추가.

## 아직 수행하지 못한 항목

- GitHub 연결 전이므로 원격 저장소 생성/push, Actions 실행, 공개 배포는 미수행.
- 로컬 주소에 대한 검증용 브라우저 접근이 ERR_BLOCKED_BY_CLIENT로 차단됨.
- 통합 테스트는 jsdom에서 수행하며 레이아웃·차트·공유 이미지 렌더링은 실제 브라우저 검증을 대신하지 않음.
- 공개 URL의 로딩/반응형 레이아웃/외부 이미지·폰트/이미지 저장은 GitHub 배포 후 확인 필요.

## 운영상 한계

- 기존 전설 데이터의 needsReview 상태를 유지했다. 수록 카드·발매일의 사실관계 및 서비스 평가값을 이번 작업에서 새로 검증하거나 변경하지 않았다.
- releaseDate는 기기 현지 날짜 기준이다. 지역별 발매 차이는 운영자가 데이터에 반영한다.
- 공유 링크는 답변·세트·경험을 담으며 카드 데이터의 버전 또는 브라우저별 가져오기 데이터는 담지 않는다.
- 데이터 관리에서 수정한 값은 해당 브라우저에만 저장된다. 전체 공개 반영은 저장소의 JSON 갱신과 재배포가 필요하다.
